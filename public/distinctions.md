# 概念辨析速查表

| 概念 A | 概念 B | 最关键区别 | 研究中常见误用 |
|---|---|---|---|
| translanguaging | code-switching | 前者不以封闭代码为分析起点；后者通常先识别代码及切换点 | 看见两种正字法就自动称为 code-switching，或反过来把所有切换都改名 translanguaging |
| translanguaging | multilingualism | 前者是实践／能力／政治框架；后者多指多语言状态或制度 | 用 multilingual classroom 直接推断课堂采取跨语教学法 |
| translanguaging | plurilingualism | 两者都反对双单语观；plurilingualism 常沿欧洲语言教育与 CEFR 谱系，translanguaging 更突出命名边界、种族化和去殖民争论 | 抹平各自政策史与知识谱系 |
| translanguaging | translingualism | 前者源于威尔士双语教育；后者常源于写作、修辞和 World Englishes | 因词形相近而当作完全同义 |
| translanguaging | translation | 前者不要求源／目标语言与文本；后者通常有委托、对应和职业规范 | 用“所有翻译都是跨语”取消翻译研究的特定对象 |
| languaging | language | 前者是过程；后者常被对象化为系统 | 把加上 -ing 当成风格变化，却仍按静态实体分析 |
| multimodality | trans-semiotizing | 前者可描述模态并置；后者强调跨模态转换与共同生成 | 仅统计图片、文字、手势数量便声称发生跨符号化 |
| multimodality | transmodalities | 后者加入关系、位置、物质和 transglobal power 的动态框架 | 把 transmodalities 当作 multimodality 的时髦同义词 |
| repertoire | named languages | 前者是行动者生命史中的可用资源；后者是社会制度分类 | 把 repertoire 写成“会英语+汉语”的清单 |
| unitary repertoire | single grammar | 前者可指实践／资源整体；后者是关于心理语法架构的更强主张 | 从社会实践连续性直接推出神经／语法系统完全不分化 |
| bilingual cognition | translanguaging | 前者是实验研究领域；后者是跨层理论与实践框架 | 用单个认知任务为整个跨语本体论背书 |
| bilingual education | translanguaging pedagogy | 前者是制度模式；后者是 stance 与设计 | 因项目有两种教学语言便假定课堂允许整合资源 |
| biliteracy | multiliteracies | 前者聚焦跨语言／文字读写；后者聚焦社会多样性与多模态设计 | 把任何数字作品都称为 multiliteracies |
| critical literacy | critical thinking | 前者明确分析文本与权力；后者更广泛分析推理与证据 | 只做事实核查却宣称完成权力批判 |
| EMI | CLIL | EMI 首要目标多为学科内容；CLIL 通常设内容与语言双目标 | 用二者标签替代对真实课堂的描述 |
| revitalization | reclamation | 前者重使用与传承；后者突出归还、主权与疗愈 | 只开发词表／App 就宣称语言已复振 |
| language difference | disorder | 差异是跨社群变异；障碍需证明对功能与参与的持续影响 | 用单语常模诊断多语儿童 |
| accommodation | UDL / TrUDL | 前者多为事后个人调整；后者是预先为差异设计 | 给学生额外时间就声称完成通用设计 |
| validity | fairness | validity 问分数解释／用途是否有依据；fairness 问不同群体的可及性与后果 | 只因题目统计可靠便宣称公平 |
| transcription | tranßcripting | 后者明确反思语言边界、模态与表征政治 | 用非常规拼写却不交代规则，使资料无法复核 |
| resistance | nonconformity | 抵抗需指向权力关系；非规范行为可能无此意图或后果 | 浪漫化一切混码为政治反抗 |
| decolonization | decoloniality | 前者也指领土／制度主权过程；后者强调持续拆解 coloniality | 用课程加入少数语言象征元素便声称完成去殖民 |
| raciolinguistics | language attitudes | 前者分析种族—语言共同建构及制度听者；后者可只测评价 | 把偏好问卷结果当作完整种族权力解释 |
| active listening | radical listening | 后者要求改变支配性听取框架与后续行动 | 复述对方话语却不改变资源或决定 |
| hard translanguaging | difficult language | hard 指关系、伦理和政治成本，不是语法难度 | 把生僻词或低熟练度互动称为 hard translanguaging |

## 三条层级纪律

1. **社会分类层**：named languages、政策、身份和制度边界。
2. **互动实践层**：参与者在具体时刻如何组合资源。
3. **认知架构层**：词汇、语法和加工系统怎样组织。

同一份证据通常只能直接支持其中一层。课堂里频繁跨语不能单独证明“单一语法”；脑成像中的共同激活也不能单独证明学校应该取消语言权利类别。
